# 租户控制台：表单型写操作 → 按钮 + 弹层

**日期：** 2026-08-13  
**状态：** 已实现  
**范围：** `/org/[orgId]` 租户成员「添加成员」、设置「转让 owner」

## 目标

与「加入项目成员」一致：页内不堆表单，改为主按钮打开居中弹层。

## 范围

| 操作 | 改动 |
|------|------|
| 添加租户成员 | 页头按钮 → 弹层（搜索候选 + 角色 + 确认） |
| 转让 owner | 按钮 → 弹层（选成员 + 确认，保留警示） |
| 编辑成员角色 | 列表只读展示 role，「编辑」→ 弹层改角色 |
| 移除 | 仍为行内按钮 + confirm |
| 设置基本信息 | 仍内联保存 |
| 加入项目成员 / 新建项目 | 已符合，不动 |

## UI

- 弹层样式对齐现有 `加入项目成员`：`fixed inset-0` 遮罩 + 白底 `max-w-md/lg` 卡片
- 打开时重置表单状态；成功后关闭并 `load()`
